# FreshCart Backend Roadmap (Planned — not implemented)

1. Config + DB connection, env validation.
2. Utils (ApiError/ApiResponse/asyncHandler) + error middleware.
3. Auth (register/login/me) + auth/admin middleware + validators.
4. Category → Product → Upload.
5. Cart → Wishlist → Address → Coupon.
6. Order → Payment → InventoryLog → Notification → Review.
7. Admin analytics/reports.
8. AI shopping (Hindi/English/Hinglish) → PDF → WhatsApp.
9. Tests (unit → integration) + docs updates per module.
